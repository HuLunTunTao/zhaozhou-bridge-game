# 验桥日 NPC 回答关键词测试清单

本文档给测试人员快速验证“验桥日”中说服类与解答类 NPC 的关键词命中逻辑。

## 1. 判定规则速记

- 说服类 NPC 的关键点配置在 `scenes/levels/bridge_tour/bridge_tour.gd` 的 `persuasion_goal.key_points`。
- 解答类 NPC 的关键点配置在 `scenes/levels/bridge_tour/bridge_tour.gd` 的 `qa_key_points`。
- 每个关键点有若干 `groups`。每组里命中任意一个同义词，算该组命中。
- 本地 fallback 判定通常要求命中“大部分组”：至少 2 组，或总组数 - 1 组，取两者中较大但不超过总组数。
- LLM 判定会看到关键点 `label` 与 `knowledge_keys`；LLM 失败时才用本地 `groups` 做硬匹配。
- 测试时建议优先使用下方“推荐测试句”，能同时覆盖 LLM 与本地 fallback 关键词。

## 5. 求教类 NPC

求教类 NPC 不用 `qa_key_points` 判定。它们用于解锁桥梁知识，供之后说服或解答时使用。

| NPC | 作用 | 可测试方向 |
| --- | --- | --- |
| 老监工 | 偏全局知识 | 扁拱、时代背景、旧制多孔小拱 |
| 老石匠 | 偏材料与工艺知识 | 二十八道券、本地青石、桥台基础、栏板望柱 |

注意：老石匠当前在关卡中是 `mentor`，不是 `qa`。因此不会走解答类 `qa_key_points` 判定。
