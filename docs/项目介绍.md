# 安济桥成：项目介绍（PPT 作者版）

> 这是一份面向非技术同学的项目总览，帮助快速理解《安济桥成》目前已经具备的游戏内容、核心玩法、角色敌人、视觉风格与资料入口。

---

## 1. 项目一句话介绍

《安济桥成》是一款以赵州桥修建故事为背景的 **2D 等距回合制战棋游戏**。玩家将跟随主角 **李春**，在充满河岸险情与工程挑战的环境中推进关卡，通过移动、技能、属性反应和任务目标来完成章节内容。

可以把它理解为：
- 不是塔防，而是 **以单位站位、回合顺序、技能释放和任务目标推进为核心** 的战棋游戏。
- 题材上结合了 **古代工匠、河工治理、桥梁修建、地势水患** 等内容。
- 当前项目已经具备 **主菜单、选关、关卡战斗、对话、过场图片、基础数值与属性系统** 等完整可玩骨架。

---

## 2. 当前游戏内容概览

目前项目的内容已经不是单纯的技术原型，而是有明确题材、角色和战斗循环的可玩版本。

### 2.1 当前可体验的内容
- 玩家可以从主菜单进入关卡选择，再进入具体战斗关卡。
- 关卡中已经有地图、单位、回合顺序、移动范围、技能释放、伤害结算、状态效果和胜负判定。
- 部分关卡支持进入前/通关后的 **过场图片演出**。
- 关卡中还支持 **对话、通知、剧情触发** 等表现形式。

### 2.2 当前内容的题材方向
- 故事围绕 **李春主持赵州桥修建** 展开。
- 关卡中的敌人与环境都围绕 **水患、河岸坍塌、浮木、暗流、工地险情** 设计。
- 己方角色不只是传统战斗职业，也包含 **工匠、测量工** 这类与工程建设直接相关的身份。

### 2.3 当前内容适合在 PPT 中突出什么
- “古代工程建设”与“战棋玩法”的结合。
- “河道治理 / 修桥过程”与“五行属性系统”的结合。
- 角色、敌人、地图地形、任务目标都服务于同一个主题：**在复杂自然环境中推进桥梁建设**。

## 3. 玩家一局会经历什么

从玩家视角看，一局游戏的体验流程已经比较完整，适合直接整理成 PPT 的“玩家体验流程页”。

### 3.1 进入关卡前
- 玩家在主菜单选择关卡。
- 某些关卡会先播放一组过场图片，用来交代剧情背景或任务前情。

### 3.2 进入关卡后
- 玩家看到等距地图、己方单位、敌方单位和界面信息。
- 当前队伍回合开始后，玩家可以选择单位行动。
- 一个单位通常要做两类事情：
  - **移动到合适位置**
  - **释放技能或执行任务动作**

### 3.3 回合中的核心操作
- 选择己方单位后，可以看到移动范围。
- 单位移动会消耗行动力（AP）。
- 技能有自己的释放范围和影响范围，也会消耗行动力。
- 如果行动力还够，单位可以继续移动或使用技能。
- 当前队伍结束后，进入下一支队伍或敌方回合。

### 3.4 玩家要面对的压力
- 敌人会从不同方向施压。
- 地形会影响移动成本与站位选择。
- 某些关卡不仅要求击败敌人，还要求 **保护目标、完成勘测、推进任务**。
- 对话、过场和事件触发会让关卡不只是“清怪”，而是带有任务推进感。

### 3.5 一局结束的方式
- 满足胜利条件后即可通关。
- 失败条件也可以被明确设置，例如关键角色被击败、护送目标失败等。
- 通关后可以返回主菜单，若有配置，也可播放结尾过场图片。

## 4. 核心玩法与系统特色

《安济桥成》的核心不是单一数值对撞，而是“站位 + 地形 + 回合 + 属性反应 + 任务目标”的组合。

### 4.1 回合制战棋玩法
- 游戏采用队伍轮流行动的战棋结构。
- 不同队伍可以由玩家操控，也可以由 AI 控制。
- 同阵营之间不会互相攻击，不同阵营之间则形成对抗。
- 因此，PPT 中可以把玩法概括为：**以队伍回合推进的策略战斗**。

### 4.2 行动力（AP）机制
- 每个单位每回合会恢复行动力。
- 移动和使用技能都会消耗行动力。
- 一个回合内，玩家需要分配“走位”和“出手”的先后顺序。
- 这让角色行动不是“一回合只能做一件事”，而是更灵活的资源分配。

### 4.3 地形与地图策略
- 游戏采用等距地图表现。
- 地形包括土、草、石路、水域等类型。
- 不同地形会影响单位移动成本，也会影响玩家的站位与推进节奏。
- 因此地图不只是背景，而是直接参与策略判断的系统层内容。

### 4.4 五行属性与“化势”系统
- 游戏有金、木、水、火、土五行属性。
- 攻击命中后，会根据攻击属性与目标当前属性，触发不同的 **化势反应**。
- 这些反应不只是简单加伤，还可能带来：
  - 持续伤害
  - 减益状态
  - 行动力惩罚
  - 特殊附加效果
- 这部分是项目最有辨识度的系统特色之一，适合在 PPT 中重点展示。

### 4.5 任务目标不只限于击败敌人
- 关卡中支持护送、勘测、特殊点位交互等内容。
- 这让玩家扮演的不是纯战斗部队，而是 **在危险环境中推进工程任务的人**。
- 与“修桥”题材结合后，任务体验会更有叙事动机。

### 4.6 剧情与演出
- 关卡可以接入对话系统。
- 也支持关卡前后的过场图片演出。
- 这意味着项目不仅有策略玩法，也在持续搭建章节叙事表达。

## 5. 当前主要角色与敌人

目前项目中的角色与敌人已经形成了较清晰的阵营结构，足够支撑 PPT 的“角色页”和“敌对势力页”。

### 5.1 己方角色

#### 李春
- 主角。
- 是玩家最核心的操作单位。
- 当前定位是兼具输出、控制与任务推进能力的核心角色。
- 技能包括近战攻击、远程投石、范围控制、地形/任务辅助等。

#### 工匠
- 己方辅助单位。
- 体现了项目“工程建设”题材中的职业身份。
- 可以承担近距离攻击与保护队友的职责。
- 相比主角，更像是帮助推进阵线与维持队伍稳定的支援角色。

#### 测量工
- 己方任务型单位。
- 是典型的“非纯战斗角色”。
- 可以执行勘测相关动作，也是护送目标类型角色的代表。
- 很适合用于体现“这不是单纯打怪游戏，而是围绕工程任务展开”的项目特征。

### 5.2 敌方单位

#### 坍岸泥鬼
- 土属性敌人。
- 形象上对应河岸坍塌、地势破坏、土体威胁。
- 适合在 PPT 中被描述为“破坏地势与阵线的重型威胁”。

#### 暗涌
- 水属性敌人。
- 代表水下暗流与近身袭击压力。
- 给人的感觉是更灵活、更危险的贴身威胁。

#### 浮木群
- 木属性敌人。
- 题材上与河道中的漂流木、冲击危险相关。
- 适合作为“高速冲撞型环境威胁”来表达。

#### 水旋
- 水属性敌人。
- 强调牵引、控制、拉扯感。
- 很适合体现河流环境本身也会成为战斗压力来源。

### 5.3 阵营视觉区分
- 主角 / 玩家单位倾向使用金黄色识别。
- 友方单位使用绿色识别。
- 敌方单位使用红色识别。
- 这种颜色设计有利于玩家快速判断场上身份，也方便 PPT 做阵营配色整理。

## 6. 美术与表现风格

项目当前的整体风格已经有较明确的视觉方向。

### 6.1 画面形式
- 2D 等距视角。
- 采用像素风表现。
- 地图以等距地块构成，强调战棋的格子感与空间层次。

### 6.2 视觉关键词
- 古代工程
- 河岸水患
- 像素风战场
- 工地、河道、险情
- 技能范围、行动范围、属性反馈

### 6.3 界面与信息表达
- 底部状态栏用于显示角色头像、生命、行动力、属性和技能。
- 单位头顶会显示生命与行动力状态。
- 技能目标区域、移动范围、回合提示等都有明确反馈。
- 这说明项目在可玩性之外，也已经具备较完整的战斗信息表达框架。

## 8. 适合 PPT 提炼的几个项目卖点

如果需要快速整理成汇报页，可以优先抓以下几点：

1. **题材独特**：以赵州桥修建与古代工匠工程为核心背景。
2. **玩法明确**：回合制战棋，强调移动、技能、地形和任务目标。
3. **系统辨识度高**：五行“化势”反应系统能形成差异化记忆点。
4. **角色身份贴合主题**：主角、工匠、测量工都服务于“修桥”主题，而非传统职业模板。
5. **敌人与环境统一服务叙事**：泥鬼、暗涌、浮木、水旋都来自河道与工地险情语境。
6. **项目完成度已有骨架**：主菜单、选关、关卡、演出、战斗系统、数据系统已经打通。
