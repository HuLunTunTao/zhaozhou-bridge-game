# 02 -- 地形绘制

> 本章介绍如何使用 Godot 的 TileMap 编辑器绘制等距地形，以及各种地形类型与移动消耗的关系。

---

## 3.1 打开 TileMap 编辑面板

1. 在场景树中，选中你要绘制的 **TileMapLayer** 节点（例如 `surface z=0`）
2. 编辑器底部会自动弹出 **TileMap** 面板（如果没有，检查底部标签栏中是否有 "TileMap" 选项卡，点击它）
3. TileMap 面板分为两个区域：
   - **左侧**：工具栏（画笔、橡皮擦、油漆桶等）
   - **右侧**：地块选择器（显示 TileSet 中所有可用的图块）

> ⚠️ 注意: 你必须先选中一个 TileMapLayer 节点，底部的 TileMap 面板才会出现。如果选中的是其他类型的节点，面板不会显示。

---

## 3.2 绘制工具

TileMap 编辑面板顶部有以下常用工具：

| 图标 | 工具 | 快捷键 | 说明 |
|------|------|--------|------|
| 笔刷 | **绘制 (Paint)** | -- | 单击或拖拽绘制地块 |
| 线段 | **线 (Line)** | -- | 按住 Shift 绘制直线 |
| 矩形 | **矩形 (Rect)** | -- | 拖拽绘制矩形区域 |
| 油漆桶 | **填充 (Bucket Fill)** | -- | 点击填充连通区域 |
| 橡皮 | **擦除 (Eraser)** | `E` | 切换擦除模式，再次点击或按 E 取消 |

### 基本绘制操作

1. 在 TileMap 面板的右侧区域中，点击选择一个地块图案
2. 将鼠标移到中央的 2D 视图中
3. **左键单击** 或 **左键按住拖拽** 来绘制地块
4. 要删除地块，按 `E` 切换到擦除模式，然后左键点击要删除的地块

---

## 3.3 使用 Terrain（地形）模式绘制

Terrain 模式是更高级的绘制方式，它能自动处理地块之间的过渡和连接。**在本项目中，地形类型与移动消耗直接关联**，因此推荐使用 Terrain 模式绘制。

### 切换到 Terrain 模式

1. 在 TileMap 面板顶部，找到 **Terrains** 选项卡（在 "Tiles" 选项卡旁边）
2. 点击 **Terrains**
3. 面板左侧会显示可用的 Terrain 列表

### 本项目的地形类型

以下是系统中定义的所有地形类型及其移动消耗：

| 地形名称 (Terrain Name) | 中文名 | 移动消耗 | 说明 |
|--------------------------|--------|----------|------|
| `earth` | 泥土地 | 1 AP | 基础地形，消耗最低 |
| `grass` | 草地 | 2 AP | 比泥土消耗翻倍 |
| `stone_road` | 石板路 | 1 AP | 与泥土相同，是道路地形 |
| `water` | 浅水 | 5 AP | 可以通行但极慢 |
| `dark_water` | 深水 | **不可通行** | 完全不可进入 |
| `water_stone` | 水中石 | 3 AP | 水中的垫脚石 |
| `decora` | 装饰 | 1 AP | 装饰性地形，不影响通行 |

> 💡 提示: 移动消耗是 Dijkstra 寻路算法中的权重值。角色有一个总行动力预算（`ap_current`，即 `ap_max`），每进入一个格子时扣除该格地形消耗值。例如 AP=100 的角色在纯草地（消耗2）上最多可走 50 格。注意：这里的消耗值不与 `move_cost_per_tile` 相乘，二者是独立的系统。

### 使用 Terrain 模式绘制

1. 在 Terrains 面板中，点击选择你想要的地形（例如 `earth`）
2. 选择绘制模式：
   - **连通绘制 (Connect)**: 新绘制的地块会自动与周围已有地块匹配边缘
   - **路径绘制 (Path)**: 按住拖拽绘制连续路径
3. 在 2D 视图中左键点击或拖拽绘制

---

## 3.4 地形与移动系统的关系

### 工作原理

当角色在地图上移动时，`MovementManager` 会这样判断每个格子：

1. 检查 `obstacle_tilemaps` 列表中的层 -- 如果该格子在障碍物层中有图块，则**不可通行**
2. 检查 `movement_tilemaps` 列表中的层 -- 读取该格子的 Terrain 数据
3. 根据 Terrain 名称查找对应的 `TileType` 类，获取移动消耗
4. 如果格子有图块但没有 Terrain 数据，**默认为 earth（消耗 1）**

### 为什么要用 Terrain 而不是普通图块

如果你用普通图块（非 Terrain 模式）绘制，地块虽然会显示图案，但 `MovementManager` 读取不到 Terrain 名称，会默认所有格子的移动消耗为 1（earth）。这意味着：

- 水面看起来是水，但角色走过去和走泥土一样快
- 深水看起来不可通行，但实际上可以走

> ❌ 常见错误: 使用普通 Tiles 模式而非 Terrain 模式绘制地图，导致地形外观与实际移动消耗不匹配。**务必使用 Terrain 模式绘制所有需要影响移动的地块。**

## 3.5 分层绘制策略

### 地表层 (surface z=0)

这是最重要的层，定义了角色可以行走的区域。

- 绘制所有可通行的地面：earth、grass、stone_road、water、water_stone
- **不要** 在这一层绘制障碍物
- 这一层的 Terrain 数据会被 `MovementManager` 读取

### 障碍物层 (Obstacle z=2)

定义不可通行的区域，如树木、岩石、建筑等。

- 在这一层放置的图块会使对应格子变为不可通行
- 与地表层叠加显示
- `MovementManager.obstacle_tilemaps` 必须包含此层

### 装饰层 (decoration z=1)

纯视觉装饰，不影响移动。

- 花草、小石子、地面纹理细节等
- 不需要添加到 `MovementManager` 的任何列表中

### 底层 (thebase z=-1, thebase z=-2)

在地表层之下显示的层。

- 深水区域的水面效果
- 悬崖下方的地面
- 纯视觉效果

### Z 值与绘制顺序

层名中的 `z=数字` 表示绘制优先级：

- 数字越大，越在上面显示（遮挡下面的层）
- `z=2`（障碍物）显示在最上面
- `z=0`（地表）在中间
- `z=-1`、`z=-2` 在最底下

> 💡 提示: 这里的 z 值是通过命名约定和节点顺序来实现的，不是 Godot 内置的 Z-Index 属性。你可以在 Node2D 的检查器中设置 Z Index 属性来微调实际的绘制顺序。

## 3.6 等距坐标与像素坐标

在等距视图中，格子坐标和屏幕像素坐标之间的转换是这样的：

```
格子坐标 Vector2i(x, y) → 像素坐标 Vector2(px, py)

px = (x - y) * 16    (半格宽度)
py = (x + y) * 8     (半格高度)
```

反向转换（像素 → 格子）：

```
x = (px / 16 + py / 8) / 2
y = (py / 8 - px / 16) / 2
```

> 💡 提示: 你不需要手动计算这些。Godot 的 TileMapLayer 提供了 `map_to_local()` 和 `local_to_map()` 方法来自动转换。这里的公式仅供理解等距坐标系。

### 等距方向对照

在格子坐标中，四个相邻格子对应的方向：

| 格子偏移 | 屏幕方向 | 游戏内含义 |
|----------|----------|------------|
| `(+1, 0)` | 右下 ↘ | 角色面朝"右前" (SE) |
| `(-1, 0)` | 左上 ↖ | 角色面朝"左后" (NW) |
| `(0, +1)` | 左下 ↙ | 角色面朝"左前" (SW) |
| `(0, -1)` | 右上 ↗ | 角色面朝"右后" (NE) |

## 3.7 常见操作技巧

### 快速填充大面积区域

1. 先用矩形工具 (Rect) 框选区域，绘制基础地形（如 earth）
2. 再用画笔工具在边缘细化（如将部分 earth 改为 grass 或 water）

### 检查地形覆盖是否完整

确保你想让角色行走的区域在 `surface z=0` 层上都有地块。空白区域（没有地块）会被视为 **不存在**，角色无法进入。

可以通过在编辑器中临时隐藏其他层来检查：

1. 在场景树中，点击 `surface z=0` 旁边的 **眼睛图标** -- 切换该层的显示
2. 隐藏其他层，只看地表层是否完整覆盖

### 检查 Terrain 是否正确分配

1. 选中 TileMapLayer
2. 在底部 TileMap 面板中，切换到 **Terrains** 选项卡
3. 用鼠标悬停在已绘制的格子上，面板底部会显示该格子的 Terrain 信息

## 3.8 地图尺寸参考

现有关卡的大致地图规模供参考（格子数）：

- 小型关卡：约 10x10 格
- 中型关卡：约 15x20 格
- 大型关卡：约 25x30 格

> 💡 提示: 由于视口分辨率为 640x360，一屏大约能显示 20x22 个等距格子（在 1x 缩放下）。相机支持 0.5x ~ 2.0x 缩放。
