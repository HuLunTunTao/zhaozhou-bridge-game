# 01 -- Godot 基础入门

> 本章面向从未使用过 Godot 的关卡设计师。如果你已熟悉 Godot 编辑器，可跳至 [02-地图创建](02-map-creation.md)。

## 1.1 什么是 Godot

Godot 是一个开源游戏引擎。我们的项目 "安济桥成" 使用 **Godot 4.6.1** 版本。你需要安装这个确切版本来打开和编辑关卡。

Godot 的三个核心概念：

| 概念 | 英文 | 类比 | 说明 |
|------|------|------|------|
| **节点 (Node)** | Node | 积木块 | 游戏中每个可见或不可见的"东西"都是一个节点。比如一个角色、一块地图、一个按钮 |
| **场景 (Scene)** | Scene | 积木模型 | 多个节点组合成一个场景，保存为 `.tscn` 文件。一个关卡就是一个场景 |
| **资源 (Resource)** | Resource | 配置表 | 存储数据的文件，比如角色属性表 `.tres`、贴图 `.png`、字体等 |

## 1.2 打开项目

### 方式一：从 Godot 项目管理器打开

1. 双击桌面上的 **Godot** 图标，启动引擎。会出现"项目管理器"窗口
2. 如果项目列表中已有 "game"，双击它即可打开
3. 如果没有，点击右侧的 **导入** 按钮
4. 在弹出的文件对话框中，导航到项目文件夹，选择 `project.godot` 文件
5. 点击 **导入并编辑**

### 方式二：从命令行打开（开发者）

```bash
godot --editor --path /你的项目路径/Godot-game
```

## 1.3 编辑器界面概览

打开项目后，你会看到 Godot 编辑器。以下是关卡设计中最常用的几个面板：

```
┌─────────────────────────────────────────────────────┐
│                    顶部菜单栏                         │
├──────────┬──────────────────────────────┬────────────┤
│          │                              │            │
│  场景树   │        2D 视图               │  检查器     │
│ (Scene)  │    （中央画布区域）            │(Inspector) │
│          │                              │            │
│          │                              │            │
├──────────┤                              ├────────────┤
│          │                              │            │
│ 文件系统  │                              │   节点      │
│(FileSystem)                             │  (Node)    │
│          │                              │            │
└──────────┴──────────────────────────────┴────────────┘
```

### 场景树面板（左上）

显示当前打开场景中的所有节点，呈树状结构。**这是你编辑关卡时最常用的面板**。

- 你可以在此处看到关卡的层次结构：哪些是地图层、哪些是角色节点
- 点击节点名称可以选中它；选中后右侧检查器会显示该节点的属性

### 检查器面板（右侧）

当你在场景树中选中一个节点后，检查器面板会显示该节点的所有可配置属性。

- 比如选中一个 Unit 节点，你可以在检查器中设置它的 `unit_data`（角色数据）和 `unit_color`（颜色）
- 属性值直接在检查器中修改，修改后会自动反映到场景中

### 文件系统面板（左下）

显示项目中的所有文件和文件夹，类似于你操作系统中的文件管理器。

- `scenes/levels/` -- 所有关卡场景
- `data/units/` -- 单位数据文件
- `data/skills/` -- 技能数据文件
- `assets/` -- 图片、音效等素材

### 2D 视图（中央）

显示当前场景的 2D 画布。你可以在这里：

- 拖拽节点来调整位置
- 使用鼠标滚轮缩放视图
- 按住鼠标中键拖拽来平移视图

## 1.4 重要操作

### 保存场景

- 快捷键：`Ctrl+S`
- 菜单：顶部菜单 -> **场景 (Scene)** -> **保存场景 (Save Scene)**

> ⚠️ 注意: 编辑后务必保存。如果标题栏中场景名后有 `(*)` 标记，说明有未保存的修改。

### 运行项目

- 按 `F5` 运行整个项目（从主菜单开始）
- 按 `F6` 运行当前打开的场景（直接进入当前关卡）

### 撤销 / 重做

- 撤销：`Ctrl+Z`
- 重做：`Ctrl+Shift+Z`

### 在场景树中查找节点

- 点击场景树面板顶部的搜索框（或按 `Ctrl+F`），输入节点名称

## 1.6 等距视角基础

本游戏使用 **等距（Isometric）** 视角。这意味着：

- 地图看起来像是 45 度俯瞰的菱形网格
- 每个格子在纹理中是 **32x32 像素**的正方形，但在游戏中显示为 **32x16 像素**的菱形
- 格子坐标使用 `Vector2i(x, y)` 表示，x 轴指向右下方，y 轴指向左下方

```
        (0,0)
       /      \
    (1,0)    (0,1)
   /    \   /    \
(2,0)  (1,1)  (0,2)
```

在 Godot 的 TileMapLayer 设置中，我们使用：

| 属性 | 值 | 说明 |
|------|------|------|
| Tile Shape | Isometric | 等距菱形 |
| Tile Layout | Diamond Down | 菱形朝下排列 |
| Tile Size | 32x16 | 显示尺寸 |
| Texture Region Size | 32x32 | 纹理中的实际尺寸 |

> 💡 提示: 你不需要手动设置这些值，因为关卡继承自 `base_level.tscn`，而地图层使用的 TileSet 已经预配置好了。
