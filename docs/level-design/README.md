## 项目快速概览

- **游戏类型**: 2D 等距回合制战棋（非塔防）
- **引擎版本**: Godot 4.6.1
- **脚本语言**: GDScript
- **视口分辨率**: 640x360（窗口 1280x720）
- **纹理过滤**: Nearest（像素风）
- **主入口场景**: `scenes/menu/main_menu.tscn`
- **关卡基类**: `scenes/levels/base_level/base_level.tscn`（class_name: BaseLevel）
- **关卡目录**: `scenes/levels/`
- **数据目录**: `data/units/`、`data/skills/`、`data/statuses/`、`data/phases/`
