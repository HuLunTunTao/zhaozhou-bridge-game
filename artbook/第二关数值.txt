## 0. 本关平衡基线 / Balance Baseline

本关不再整体上调我方基础面板，而是按“玩家已通过第一关，并获得4选1中的任意一项成长”来做平衡。也就是说，李春、测量工、工匠默认沿用上一关的基础数值与技能框架，难度增长主要来自敌方类型、人形压点、固定召唤Boss和中央绘样台争夺，而不是我方面板硬抬。

```text
李春基线 / li_chun_base:
max_hp 130
base_atk 24
ap_max 100
move_cost_per_tile 8

测量工基线 / survey_worker_base:
max_hp 80
base_atk 12
ap_max 85
move_cost_per_tile 10

工匠基线 / craftsman_base:
max_hp 110
base_atk 18
ap_max 90
move_cost_per_tile 9
```

上一关结算成长直接继承到本关，不重置。

## 1. 关卡定位 / Stage Role

```text
关卡ID / stage_id: chapter1_stage2
关卡名称 / stage_name: 弧拱定式
定位 / stage_role: 方案争夺关 + 中央据点防守关 + 固定召唤Boss关
Boss / boss: 旧制监工
难度 / difficulty: 中低
推荐回合上限 / turn_limit: 12
```

### 本关核心目标 / Core Goal

本关保留你原来定下的三层任务结构：

第一层是取参。
第二层是守住中央绘样台。
第三层是完成定拱，并通过持续击破被Boss驱使的小怪来迫使Boss败退。

---

## 2. 关卡机制 / Stage Mechanics

## 2.1 参数点机制 / Parameter Point Mechanic

本关共有3个参数点：

```text
参数点A / parameter_a: 河宽
参数点B / parameter_b: 坡度
参数点C / parameter_c: 石重
```

完成全部3个参数点后，李春才能在中央绘样台执行最终关卡交互“执墨定拱”。

### 参数点交互规则 / Parameter Interaction Rules

```text
测量工 / survey_worker:
可在相邻1格使用交互技能完成参数采集
交互消耗 ap_cost: 40

李春 / li_chun:
可代行参数确认
不是技能，是关卡交互动作
交互消耗 ap_cost: 45
每回合最多1次
```

这样测量工仍然重要，但不会因为测量工阵亡而直接锁死流程。

---

## 2.2 绘样台机制 / Drafting Platform Mechanic

中央绘样台是本关的核心争夺区域。

```text
绘样台 / drafting_platform:
位置: 地图中央2x2区域（(-11,-11),(-11,-10),(-12,-10),(-12,-11)）
用途:
1. 李春执行“执墨定拱”的唯一地点
2. Boss固定驻守区域
3. 若敌方在敌方回合结束时占据绘样台，则Boss下回合召唤数+1
```

### 执墨定拱 / Final Drafting Action

```text
关卡交互ID / stage_interact_id: finalize_arch_design
名称 / name: 执墨定拱
执行者 / performer: 李春
执行地点 / location: 绘样台
前置条件 / requirements:
    1. 三个参数点全部完成
    2. 李春位于绘样台
行动力消耗 / ap_cost: 35
效果 / effect:
    1. 本关进入“定拱完成”状态
    2. Boss可被流程性击败
```

---

## 2.3 固定召唤Boss机制 / Stationary Summon Boss Mechanic

本关Boss旧制监工不移动，不参与普通近战推进，主要通过召唤与督令制造场面压力。

### Boss败退条件 / Boss Defeat Condition

```text
胜利流程 / win_flow:
1. 三个参数点全部完成
2. 李春执行“执墨定拱”
3. 累计击破 8 名受驱役敌人 / defeated_driven_enemy_count >= 8
4. 旧制监工自动败退，关卡胜利
```

这里的“受驱役敌人”包括本关所有由Boss驱使出现的敌方单位，初始敌人与后续召唤敌人都计入累计击破数。

### 场上敌人数上限 / Enemy Field Cap

```text
敌方场上人数上限 / enemy_field_cap: 5
```

Boss每回合优先召唤；若场上人数已满，则改为给现存敌军施加督令强化。

## 4. 地格与场景对象 / Terrain and Stage Objects

为了避免第二关机制过多，这一关只保留最少的场景对象。

### 普通地格 / normal_tile

* 无特殊效果

### 绘样台 / drafting_platform

* 李春可执行“执墨定拱”
* 敌方占据时使Boss下回合召唤数+1

### 桥模区 / bridge_model_zone

* 无额外数值效果
* 作为中央争夺与卡位核心区域

### 参数点 / parameter_point

* 可由测量工或李春交互
* 完成后永久失效

### 石料障碍 / stone_obstacle

* 不可通行
* 用于制造重墩石像的堵路价值

## 12. 这版第二关的平衡抓手 / Balance Anchors

这一关真正拉开和第一关区别的，不是给所有单位加一堆新能力，而是三件事：

第一，中央区域会反复被争夺，工匠从护卫单位正式变成主力前排。
第二，李春开始拥有真正的范围清场手段，技能选择更接近“主导型战术核心”。
第三，Boss本身不动，但会不断把场面推高，玩家必须一边取参、一边控中、一边清怪，才能把“旧制监工”从流程上击败。这个方向和你原来给第二关定下的“抢参数点”和“守中央”是完全一致的。
