## 1. 核心战斗规则 / Core Combat Rules

### 1.1 回合顺序 / Turn Order

```text
主角回合 hero_turn
→ 敌方回合 enemy_turn
→ 我方辅助单位回合 ally_support_turn
→ 返回主角回合 hero_turn
```

### 1.2 行动力规则 / Action Point Rules

* **李春 / Li Chun**

  * 可自由分配行动力进行多次移动、多次攻击、多次施放技能
  * 只要行动力足够，即可继续行动

* **我方辅助单位 / ally_support_units**

  * 也拥有行动力
  * 每回合最多进行 1 次攻击
  * 剩余行动力可用于移动、交互、辅助动作

* **敌方单位 / enemy_units**

  * 显示当前行动力
  * 按预设行为模板行动（设计AI）

### 1.3 行动力恢复与休息回复 / AP Reset and Rest Recovery

* 我方单位在自己回合开始时，行动力恢复至上限
* 我方单位在自己回合结束时，按剩余行动力恢复生命值

```text
恢复生命 / hp_recover
= ceil(剩余行动力 remaining_ap / 行动力上限 ap_max × 最大生命值 max_hp × 10%)

单回合恢复上限 / recover_cap
= ceil(max_hp × 12%)
```

### 1.4 伤害公式 / Damage Formula

```text
最终伤害 / final_damage
= round(基础攻击力 base_atk × 技能倍率 damage_ratio × 化势倍率 phase_multiplier)
+ 化势附加伤害 phase_bonus_damage
```

### 1.5 属性附着规则 / Element Attachment Rules

* 非人类敌人初始带有 **2层固有属性 / 2 innate element stacks**
* 技能命中后按技能说明附着属性量
* 结算顺序如下：

```text
1. 结算基础伤害 base_damage
2. 判定同气 / 化势 / 逆势
3. 消耗目标当前附着属性量 target_current_element_amount
4. 若攻击方仍有剩余附着量，则附着到目标
5. 化势附加伤害不再触发二次化势
```

### 1.6 敌方固有属性回补 / Enemy Innate Element Refresh

敌方单位在自己行动开始前执行：

```text
若当前附着属性 ≠ 固有属性：
    清除1层当前属性
若当前无附着：
    附着 1 层固有属性
若当前附着属性 = 固有属性：
    保持不变
```

### 1.7 同气、逆势与普通异属性接触 / Same, Adverse and Plain Contact

#### 同气 / Same Phase

* 攻击属性 = 目标当前附着属性
* 不触发化势
* 不消耗属性量
* 不改变当前附着

#### 逆势 / Adverse Phase

* 目标当前附着属性克制攻击属性
* 统一显示“逆势”
* **伤害倍率 / damage_multiplier = 0.80**
* 无额外效果

#### 普通异属性接触 / Plain Cross-Element Contact

* 不属于化势
* 不属于逆势
* 不属于同气
* 仅进行属性量对消与剩余附着
* 不显示额外提示
* 不附带额外效果

### 1.8 无属性规则 / Non-Element Rules

* **无属性 → 无属性 / non_element_to_non_element**

  * 伤害倍率 = 1.15

* **无属性 → 有属性 / non_element_to_element**

  * 正常伤害
  * 不消耗目标属性量

* **有属性 → 无属性 / element_to_non_element**

  * 正常伤害
  * 按技能说明附着属性

## 4.4 地格配置 / Terrain Rules

### 普通地格 / normal_tile

* 无特殊效果

### 浅水格 / shallow_water

* 进入时额外消耗 4 点行动力
* 若单位在此结束行动，则获得 1 层水属性

### 激流格 / rapid_water

* 不可主动在此结束行动
* 若因拖拽、击退、冲撞进入，则立即受到 12 点无属性伤害，并沿流向再位移 1 格

### 坍岸格 / collapsed_bank

* 进入时额外消耗 6 点行动力
* 测量工不能在其上执行勘测
* 若单位在坍岸格被击退，则额外后退 1 格

### 候选桥位 / bridge_candidate

* 3 个勘测点完成前不可交互
* 完成后，李春可执行“相水定址”

### 撤离区 / evac_zone

* 桥位确认后激活
* 至少 1 名测量工在此结束回合即满足撤离要求
