```text

推荐回合上限 / turn_limit: 15
```

### 本关核心目标 / Core Goal

本关的主问题不是单纯击败Boss，而是同时守住四件事：

1. 桥体总稳定值 / overall_bridge_stability
2. 左桥台稳定值 / left_pier_stability
3. 右桥台稳定值 / right_pier_stability
4. 四小拱泄洪状态 / side_arch_open_count

玩家需要一边守桥台、一边开泄洪、一边处理桥面障碍和水压敌军，最后在泄洪条件足够稳定时击败怒水。

## 1.3 桥台压力 / Pier Pressure Rules

桥台是本关的第二条生命线。

### 变化规则 / Pier Stability Changes

```text
若桥台噬者在敌方回合结束时相邻左桥台:
    left_pier_stability -= 1

若桥台噬者在敌方回合结束时相邻右桥台:
    right_pier_stability -= 1

若洪锋或漂木群·洪水版以冲撞效果命中桥台:
    对应桥台稳定值 -= 1
```

### 失败联动 / Fail Link

```text
若 left_pier_stability <= 0:
    立即判负

若 right_pier_stability <= 0:
    立即判负
```

---

## 1.4 桥体总稳定值 / Overall Bridge Stability

桥体总稳定值代表整桥在当前洪压下还能承受的总负荷。

### 变化规则 / Overall Stability Changes

```text
按 side_arch_open_count 结算固定洪压损失

若漂木群·洪水版封住已开启小拱:
    不立即扣桥体总稳定值
    但该小拱本回合不计入已开启数

若泥沙魇结束行动时位于桥面关键格:
    overall_bridge_stability -= 1
```

### 失败联动 / Fail Link

```text
若 overall_bridge_stability <= 0:
    立即判负
```

## 3. 场景对象与地格 / Stage Objects and Tiles

### 普通桥面 / bridge_tile

* 无额外效果

### 激流桥缘 / rapid_edge_tile

* 不可主动结束行动
* 被击退进入时立即受到12点无属性伤害，并继续沿流向位移1格

### 淤泥格 / silt_tile

* 进入时额外消耗4点行动力
* 在其上结束行动时，下回合首次移动额外消耗2点行动力

### 小拱节点 / side_arch_node

* 可被“启肩泄洪”交互
* 若被漂木群·洪水版占据，则视为 blocked

### 左桥台 / left_pier

* 可被“抢修桥台”交互
* 可被桥台噬者持续攻击

### 右桥台 / right_pier

* 可被“抢修桥台”交互
* 可被桥台噬者持续攻击

### 桥心观察位 / bridge_center_watch_point

* 李春站在此处时，新技能的作用范围最容易覆盖全桥
* 不提供额外数值加成

```text
resolve_side_arch_open_count():

    for arch_state in [side_arch_1_state, side_arch_2_state, side_arch_3_state, side_arch_4_state]:
```

```text
resolve_flood_pressure():
    resolve_side_arch_open_count()

    if side_arch_open_count == 0:
        overall_bridge_stability -= 2
        damage_lower_pier(1)
    elif side_arch_open_count == 1:
        overall_bridge_stability -= 2
    elif side_arch_open_count == 2:
```

### Boss受伤判定伪逻辑 / Boss Damage Gate

```text
apply_damage_to_wrathful_flood(damage):
    resolve_side_arch_open_count()

    if side_arch_open_count == 0:
        return 1
    elif side_arch_open_count == 1:
        return min(damage, 6)
    elif side_arch_open_count == 2:
        return min(damage, 12)
    else:
        return damage
```
