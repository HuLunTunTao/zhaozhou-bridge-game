## 0. 本关定位 / Stage Role

```text
关卡ID / stage_id: chapter1_stage3
关卡名称 / stage_name: 二十八券
定位 / stage_role: 结构施工关 + 左右平衡机制关 + Boss机制关
Boss / boss: 偏载傀
难度 / difficulty: 中高
推荐回合上限 / turn_limit: 14
```

### 本关核心目标 / Core Goal

本关的核心不是单纯清空敌人，而是同时完成三件事：

1. 推进左券与右券的施工值
2. 维持左右两边的券值差不失衡
3. 完成合龙后击败偏载傀

这一定位与前面总表中“维持左右施工平衡、修正失衡、完成合龙”的任务描述一致。

## 1. 核心机制：左右券值 / Core Mechanic: Left and Right Arch Values

## 1.1 机制变量 / Core Variables

```text
左券值 / left_arch_value: int
右券值 / right_arch_value: int
桥体稳定值 / bridge_stability: int

```

### 初始值 / Initial Values

```text
左券值 / left_arch_value: 2
右券值 / right_arch_value: 2

是否完成合龙 / arch_closed: false
```

### 目标值 / Target Values

```text
左券目标 / left_target: 8
右券目标 / right_target: 8
```

---

## 1.2 左右差值判定 / Balance Difference Rules

```text
差值 / arch_gap = abs(left_arch_value - right_arch_value)
```

### 平衡状态 / Balance States

#### 均衡 / balanced

```text
条件 / condition: arch_gap <= 1
效果 / effect:
    无额外惩罚
    合龙后Boss可正常受伤
```

#### 偏衡 / tilted

```text
条件 / condition: arch_gap == 2 or arch_gap == 3
效果 / effect:
    Boss获得“偏载护核”
    直接受到的伤害上限 = 8
```

#### 失衡 / unstable

```text
条件 / condition: arch_gap >= 4
效果 / effect:
    Boss获得“偏载护核”
    直接受到的伤害上限 = 1
    每次敌方回合结束后，桥体稳定值 -1
```

这套规则把第三关的压力集中在“差值”本身上，玩家每回合都要看左右值，而不是只看清怪速度。

---

## 1.3 桥体稳定值 / Bridge Stability

桥体稳定值代表整座拱桥当前能承受的施工误差与破坏压力。

### 变化规则 / Stability Changes

```text
当 arch_gap >= 4 且敌方回合结束时:
    bridge_stability -= 1

当脱缝鬼在缝口位结束敌方回合时:
    bridge_stability -= 1
```

### 失败条件关联 / Fail Link

```text
若 bridge_stability <= 0:
    立即判负
```

---

## 1.4 施工推进 / Construction Progress

本关推进券值的主要方式是运石工完成搬运与入券。

### 单次推进规则 / Single Progress Rule

```text
运石工携石后，在左券台或右券台执行“运石入券”：
    对应侧 arch_value +1
    单侧最大不超过 8
```

### 额外限制 / Limits

```text
若某侧 arch_value 已达到 8:
    该侧不能继续加值
```

这样就不会出现一边无限堆高、另一边严重落后的玩法漏洞。

```

use_transport_stone(unit):
    if unit is stone_carrier:
        if unit.on_tile == stone_yard and unit.carrying_stone == false:
            unit.carrying_stone = true
        elif unit.on_tile == left_arch_platform and unit.carrying_stone == true:

            unit.carrying_stone = false
        elif unit.on_tile == right_arch_platform and unit.carrying_stone == true:
            right_arch_value = min(right_arch_value + 1, 8)
            unit.carrying_stone = false
```

### 差值结算伪逻辑 / Gap Resolve Pseudo Logic

```text
resolve_arch_gap():
    arch_gap = abs(left_arch_value - right_arch_value)

    if arch_gap >= 4:
        boss_damage_cap = 1
    elif arch_gap >= 2:
        boss_damage_cap = 8
    else:
        boss_damage_cap = normal
```

### Boss技能伪逻辑 / Boss Skill Pseudo Logic

```text
boss_use_shift_the_load():
    if left_arch_value == right_arch_value:
        random_side -= 1
    elif left_arch_value > right_arch_value:
        right_arch_value -= 1
    else:
        left_arch_value -= 1

    left_arch_value = max(left_arch_value, 0)
    right_arch_value = max(right_arch_value, 0)
```

### 敌方回合结束伪逻辑 / Enemy Turn End Pseudo Logic

```text
enemy_turn_end():
    arch_gap = abs(left_arch_value - right_arch_value)

    if arch_gap >= 4:
        bridge_stability -= 1

    for each joint_eroding_shade:
        if unit.on_left_joint or unit.on_right_joint:
            bridge_stability -= 1
```

### 合龙伪逻辑 / Crown Closure Pseudo Logic

```text
close_crown_joint():
    if left_arch_value >= 8 and right_arch_value >= 8 and abs(left_arch_value - right_arch_value) <= 1:
        arch_closed = true
```

## 11. 这版第三关的平衡抓手 / Balance Anchors

这一关真正的压迫感来自三条线同时拉扯：
一条是运石工推进左右券值，
一条是错券兵和偏载傀持续把差值拉开，
一条是脱缝鬼和失衡状态不断消耗桥体稳定值。

这样玩家不会只盯着Boss血条，而会一直围绕“哪一边落后、谁去补、谁去守、什么时候合龙”来做判断。这也正好对应你给第三关定下的“边打边维持结构平衡”的总方向。
